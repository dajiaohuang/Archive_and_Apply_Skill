# Academic Applications Workspace

- `templates/`: language-selected starting points; official prompts always take precedence
- `writing-samples/`: writing samples and provenance notes
- `<program>/`: target prompt, official requirements, fit research, drafts, and final files

First record the program, degree, intake term, deadline and time zone, exact prompts, word/page/file limits, recommendation requirements, and verification date. Create only documents the program requires. Let each prompt define the boundary between statements; do not perform name-only customization.
